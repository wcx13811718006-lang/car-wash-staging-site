Using the library

Use evidence boundaries, not headlines alone.

These records support comparison and internal discussion. Open the controlling source before reusing a claim.

1. Select

Filter by hazard, geography, theme, and implementation stage. A case is a bounded action, not an entire plan or program universe.

2. Read evidence

Separate measured outcomes from reported or anticipated benefits. Missing evidence is shown as a limit, not silently filled.

3. Test transferability

Compare governance, scale, climate mechanism, implementation stage, and site constraints before applying a lesson elsewhere.

4. Cite and correct

Use the case citation and source link. Report broken links, inaccurate fields, or accessibility problems to the project team.

Methodology and definitions

Cases are screened for adaptation relevance, bounded action, usable source evidence, and review needs. Inclusion in this staging library does not by itself establish effectiveness or publication approval.

Planned / pilot
Action is proposed, funded, designed, or being tested. Benefits must not be described as measured outcomes.
Implemented / operational
Action exists or is operating. Outcome claims still require explicit source evidence.
Transferability
Conditions under which an approach may inform another place; it is not a guarantee of equivalent results.
Update cycle
Source status and case fields are checked through a human-reviewed workflow before a new immutable snapshot is activated.
